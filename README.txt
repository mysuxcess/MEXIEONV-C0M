MEXIEON deliverable

One-click launch:
- Double-click OPEN_MEXIEON.cmd to open the marketplace.
- The marketplace file is Mexieon.com.html.
- The admin / V9 console link opens mexieon-v9.html from the same folder.

Package notes:
- Product catalog renders 3,000 listings.
- Product cards use live real-item photo URLs with local generated art as a fallback if an image cannot load.
- Internal navigation uses in-page hash routing, so menu links, catalog links, product links, cart, orders, account, wholesale, seller, help, and admin routes stay inside the app.
